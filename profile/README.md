## About

We are a student community at **Don Bosco Institute of Technology (DBIT), Bengaluru** that builds, learns and ships open source together. This organization holds our club projects, event tools and student-built apps.

## Projects

| Project | What it does |
| --- | --- |
| [DBIT-PageCraft](https://github.com/OSSC-DBIT/DBIT-PageCraft) | Chemistry assignment front page generator for DBIT/VTU |
| [chem-event-reg](https://github.com/OSSC-DBIT/chem-event-reg) | Chemistry department event registration platform |
